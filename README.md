# Smart-Resume-Parser-CSV-Exporter
Smart Resume Parser &amp; CSV Exporter is an AI-powered tool that extracts key information from resumes and generates structured CSV files. 
Designed for recruiters, HR teams, and data enthusiasts, it streamlines the resume screening process and organizes candidate data efficiently.

## 🚀 Features

Automated Resume Parsing: Extracts personal details, education, skills, experience, and contact info.

CSV Generation: Converts extracted resume data into a clean, structured CSV format.

Supports Multiple Formats: Handles PDF, DOCX, and TXT resumes.

Batch Processing: Parse multiple resumes in one go.

Customizable Fields: Select which resume data points to include in CSV.

## 🎯 Use Cases

HR automation and talent acquisition

Candidate database creation

Resume analytics and reporting

Data preprocessing for AI/ML recruitment models

## 🛠 Technologies Used

Python – Main programming language

LangChain – AI workflow and document processing

OpenAI / GPT models – NLP for resume understanding

Pandas – CSV generation and data manipulation

PyPDF2 / docx / textract – Resume file parsing

## ✅ Conclusion

Smart Resume Parser & CSV Exporter simplifies and automates the resume screening process by converting unstructured resume data into organized CSV files. It saves time for HR teams, enhances data accuracy, and enables faster decision-making. With AI-powered parsing and customizable output, this tool is a reliable solution for efficient talent management and data-driven recruitment.
